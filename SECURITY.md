# Sicherheitsrichtlinie (Security Policy)

## Unterstützte Versionen

| Version | Unterstützt |
|---|---|
| 2.x (aktueller `main`-Branch) | :white_check_mark: |
| 1.x (Legacy PHP) | :x: |

## Sicherheitslücken melden

Wenn du eine Sicherheitslücke oder ein Datenschutzproblem in dieser Plattform entdeckst, melde dies bitte **nicht** über einen öffentlichen GitHub Issue.

### Kontakt

Am einfachsten meldest du eine Lücke vertraulich direkt über GitHub:
* **GitHub:** [Sicherheitslücke melden](https://github.com/NelsStorch/schichtplan_v2/security/advisories/new) (Tab *Security* → *Report a vulnerability*)

Alternativ per E-Mail:
* **E-Mail:** [admin@cevi-schichtplan.ch](mailto:admin@cevi-schichtplan.ch)

Bitte gib in deiner Meldung folgende Details an:
1. Eine präzise Beschreibung der Schwachstelle
2. Schritte zur Reproduktion (Proof-of-Concept, Requests oder Screenshots)
3. Betroffene Komponente oder Domain (z. B. `apps/backend`, `apps/login`, etc.)

Wir bemühen uns, kritische Sicherheitsprobleme schnellstmöglich zu prüfen und innerhalb angemessener Frist zu beheben.
